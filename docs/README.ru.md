# 🔥 TSDoom

🌐 _[English](../README.md) | Русский | [中文](README.zh.md) | [日本語](README.ja.md) | [Español](README.es.md)_

Движок DOOM, написанный с нуля целиком на **TypeScript** и работающий в браузере через HTML5 `<canvas>`. Без WebGL, без фреймворков — только чистый программный рендеринг, как в 1993 году.

TSDoom загружает оригинальный **DOOM1.WAD** и воссоздаёт классический движок id Tech 1: BSP-рендеринг, секторное освещение, анимированные текстуры, hitscan-оружие, двери, лифты, давилки, подбор предметов и многое другое.

## 🚀 Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) (v18+)
- Копия `DOOM1.WAD` (shareware-версия оригинального DOOM)

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/TSDoom.git
cd TSDoom

# Установить зависимости
npm install

# Поместить WAD-файл
# Скопируйте DOOM1.WAD в директорию data/
cp /path/to/DOOM1.WAD data/

# Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере и играйте.

### Сборка для продакшена

```bash
npm run build
npm run preview
```

## 🎮 Управление

| Действие               | Клавиша           |
| ---------------------- | ----------------- |
| Вперёд                 | `W`               |
| Назад                  | `S`               |
| Влево (стрейф)         | `A`               |
| Вправо (стрейф)        | `D`               |
| Поворот / Прицел       | Мышь              |
| Стрельба               | Левая кнопка мыши |
| Использовать / Открыть | `E` или `Space`   |
| Бег                    | `Shift`           |
| Выбор оружия           | `1`–`7`           |
| Меню / Пауза           | `Escape`          |
| Помощь                 | `F1`              |

> Нажмите на canvas, чтобы захватить указатель мыши (pointer lock).

## 🔧 Технологии

| Компонент  | Технология                           |
| ---------- | ------------------------------------ |
| Язык       | TypeScript                           |
| Сборщик    | Vite                                 |
| Рендеринг  | HTML5 Canvas 2D (программный рендер) |
| Целевой ES | ES2024                               |

**Ноль runtime-зависимостей.** Весь движок написан с нуля — TypeScript и Vite используются только как dev-зависимости.

DOOM является зарегистрированной торговой маркой id Software / ZeniMax Media / Microsoft. Данный проект — независимая образовательная реимплементация движка — **не** содержит каких-либо защищённых авторским правом игровых данных. Вы должны предоставить собственный файл `DOOM1.WAD`.
